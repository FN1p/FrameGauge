## Summary
Customizable performance HUD and editor monitoring toolkit for Godot 4.

## Description
FrameGauge helps Godot developers inspect runtime performance without leaving their game. Configure a compact HUD, select individual metrics, and use a resizable, transparent overlay for 2D and 3D projects.

- FPS, frame time, average FPS and rolling 1% low.
- Frame graphs and rendering, physics and memory counters.
- Custom metric presets, position, scale and background opacity.
- In-game settings and a configurable shortcut (Alt+F9 by default).
- Optional local editor telemetry and a dedicated settings dock.
- No account, external service or paid tier required.

Install the addon ZIP into your project root, beside project.godot. Enable FrameGauge Free in Project Settings > Plugins. Press F9 to toggle the HUD or Alt+F9 for settings.

This is a beta. Hardware utilization and render timing depend on OS and renderer. Windows CPU/GPU utilization percentages are not implemented. Linux host utilization is experimental; only claim supported platforms after validation. Engine video memory is not total GPU VRAM utilization. Please report reproducible issues via GitHub.

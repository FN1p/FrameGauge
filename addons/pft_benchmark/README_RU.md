# FrameGauge — 0.8.0 Beta

Бесплатный инструмент мониторинга Godot от PFT Studio. Платная версия пока не планируется. Целевая версия — Godot 4.7.2. Предыдущая сборка 0.7.1 проверена пользователем в игре на Windows; эта сборка 0.8.0 требует финальной проверки. Лицензия MIT включена, требуется утверждение издателем.

## Установка и обновление
Скачайте ZIP аддона, а не демопроекта. Распакуйте его рядом с `project.godot`: архив уже содержит `addons/`. Правильный путь — `res://addons/pft_benchmark/plugin.cfg`, не `res://addons/addons/pft_benchmark/plugin.cfg`. При ручном копировании поместите внутреннюю папку `pft_benchmark` в существующую `addons/`. В Project > Project Settings > Plugins включите **FrameGauge Free**. Появится панель FrameGauge; добавится autoload `PFTBenchmark`. Перед удалением папки отключите плагин.

При обновлении PFT Benchmark 0.5.0 остановите игру, закройте редактор, замените прежнюю папку аддона и откройте проект снова. Внутренние пути, ключи `pft_benchmark/`, autoload, канал отладчика и имя локального файла сохранены для совместимости. Настройки вашей игры должны сохраниться. В переименованном демопроекте Godot может использовать новую папку пользовательских данных: сохранённый внешний вид демо тогда потребуется настроить повторно. Сделайте резервную копию. Не заменяйте project.godot своей игры файлом из демо.

## Настройки и управление
- F9 — показать/скрыть HUD, Shift+F9 — режим, Ctrl+F9 — сброс статистики, Alt+ЛКМ — перенос, Ctrl+Shift+F9 — исходный угол, Alt+F9 (по умолчанию) — полное меню настроек, комбинация меняется в Controls, Esc — отмена несохранённых изменений. Позиция сохраняется до перезапуска.
- Setup: включение, показ при запуске, необязательная телеметрия редактора, разрешение release-экспорта. Style: режим, язык, угол, масштаб 40–200%, непрозрачность фона 0–100%, общая непрозрачность 35–100%, акцент, частота обновления, окно статистики. Предпросмотр демонстрационный.
- Metrics: 24 отдельных переключателя, групповой выбор и пресеты Minimal/Standard/Full. Ручной выбор переводит в Custom. Live: последние данные отладочной сессии. Apply & save и перезапуск игры применяют изменения.
- В игровом меню Alt+F9 получите доступ к ползункам, размерам 50/75/100%, углам и индивидуальным метрикам. Save & close сохраняет `user://pft_benchmark_appearance.cfg`; эти значения имеют приоритет над настройками проекта. Project defaults показывает значения проекта; сохраните, чтобы применить. Меню не ставит игру на паузу. HUD имеет русский и английский языки, редактор и демо преимущественно английские.
- По умолчанию HUD отключён в release-экспорте и headless. Телеметрия идёт только в отладчик Godot, без внешних сервисов; скрытие HUD прекращает сбор и передачу.

## Показатели и ограничения
FPS — счётчик движка; Frame Time — измеренный интервал между вызовами _process, не GPU time. Средний FPS = кадры / время. 1% Low — обратное среднему времени худших ceil(1%) кадров, минимум 100 кадров, окно по умолчанию 600. Пики >33,333 мс, min/max и график относятся к скользящему окну. Process/Physics time — мониторы движка. Render CPU/GPU — время рендера основного viewport при включённом измерении; недоступное значение N/A. Не включайте измерение одновременно с другим инструментом, управляющим таймингом viewport. Engine memory и Video memory — счётчики движка, а не полная память процесса/видеокарты. Host free/total RAM — физическая память системы. Linux CPU/DRM GPU — экспериментальная системная загрузка, не загрузка конкретной игры. Windows CPU/GPU в процентах, температуры и частоты не реализованы. Draw Calls, примитивы и объекты — глобальные счётчики рендера, не всегда треугольники. HUD update CPU — только время синхронного обновления HUD, а не полная нагрузка.

## Демополигон
Откройте project.godot в Godot 4.7 и запустите F5. Есть 0–1024 физических тела, 0–1600 мешей без коллизий, профили Low/Medium/High/Extreme, тени, импульс, вращение камеры. 2D-сцена demo/main.tscn (F6).
- A/B: сначала Uncap FPS; тест замораживает тела и камеру, сравнивает HUD off/on, по 2 с прогрева и 5 с измерения. Повторите несколько раз. Для чистого HUD отключите телеметрию и render timing. Драйвер, нагрев и фоновые процессы влияют на результат.
- Минутный тест: прогрев 3 с, импульс каждые 5 с, неподвижная камера, средний FPS, 1% Low за весь прогон (N/A свыше 200 000 кадров), медленные кадры. Это не строго детерминированный физический тест.
- Полный архив: `python tools/validate.py` проверяет структуру; `python tools/validate.py --godot путь_к_godot` дополнительно запускает импорт и тесты в движке. См. VALIDATION.md, RELEASE_CHECKLIST.md.

## Лицензия и ИИ
Включена MIT. При разработке использованы ИИ-ассистенты для кода и дизайна. Показатели производительности не генерируются ИИ; они получаются из движка, ОС и замеров времени. Перед публикацией требуется реальная проверка и утверждение лицензии.

## Быстрая настройка 0.8.0
Нажмите **Settings** в HUD или **HUD settings / size** в 3D Lab; Настраиваемая комбинация (Alt+F9 по умолчанию) работает, даже если HUD скрыт. В Appearance выбираются режим, угол, размер (50/75/100% или ползунок), фон и общая прозрачность. В Metrics отмечаются видимые показатели; ручной выбор переводит в Custom. Выбор обычного пресета восстанавливает набор для этого режима. Save & close сохраняет размер, прозрачность, режим, угол и выбранные метрики локально. В Controls нажмите на текущую комбинацию и задайте новую (например, Ctrl+Shift+B). В Advanced — частота обновления, размер окна статистики и графика, тип графика и измерение времени рендера. Apply сохраняет, не закрывая меню; Save & close сохраняет и закрывает. Cancel, Esc и × возвращают последние сохранённые настройки. Project defaults показывает настройки проекта; сохраните, чтобы оставить их. При уменьшении окна статистики старые кадры могут быть потеряны, отмена их не восстанавливает. При захваченной мыши используйте назначенную комбинацию. Тестовое меню не ставит игру на паузу.

## Проверка перед выпуском
Полный проект включает GitHub Actions для Godot 4.7.2 (Linux и Windows). На ПК с графической средой выполните `python tools/validate.py --godot путь_к_Godot --gui`: импорт, проверка GDScript, тесты логики, меню и запуск обеих демосцен. Проверка идёт во временной копии с уникальным именем проекта. До фактического успешного запуска не считать сборку проверенной.

## Проверка на Windows
Запусти `CHECK_WINDOWS.cmd` в полном проекте, выбери исполняемый файл Godot 4.7.2 (желательно `_console.exe`). Требуется Python 3. Проверка запускается на временной копии, пишет `FRAMEGAUGE_QA.log`. При ошибке пришли лог. Для Forward+ и Mobile доступен параметр `--renderer` в `tools/validate.py`.
